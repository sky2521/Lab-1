# Generative AI - Lab Assignment 01: Variational Autoencoder (VAE)

## Aim
To build and train a Variational Autoencoder (VAE) using PyTorch and the MNIST dataset to generate handwritten digits, compare reconstructed images with original images, and visualize the two-dimensional latent space.

## Software and Libraries Used
- Python
- Google Colab / Jupyter Notebook
- PyTorch & Torchvision
- Matplotlib
- MNIST Dataset

## Repository Contents
- `Lab1.ipynb`: Python Jupyter Notebook containing data loading, VAE architecture (Encoder, Latent Space sampling, Decoder), loss functions (Reconstruction loss + KL divergence), training loop, and visual latent space analysis.
- `Lab 1.docx`: Complete university laboratory record and report with theoretical background, code explanation, output figures, and analysis.
